# Контекстное окно и структурированный вывод

Контекстное окно — ограниченный объём данных, доступных модели в одном запросе. При подготовке запроса сохраняйте системную инструкцию и текущий вопрос. Структурированный вывод проверяйте по схеме: обязательные поля, типы и допустимые значения; некорректный результат отклоняйте.
